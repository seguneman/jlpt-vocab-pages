日本語

1. 概要

本アプリは、日本人の韓国語学習者がオフラインで単語を学習するためのモバイルアプリです。 利用者の個人情報を収集せず、外部サーバーへデータを送信しません。 ただし、無料運営のため広告（Google AdMob）SDK を使用しており、広告 SDK 自体が一部の情報を収集する場合があります。

2. 収集しない情報

  • 氏名、メールアドレス、電話番号、住所
  • 位置情報
  • 連絡先、写真、ファイル、SMS
  • マイク、カメラ
  • 会員登録／ログイン情報（ログイン機能自体がありません）

3. 端末内に保存される情報

以下は利用者の端末内（localStorage）にのみ保存され、外部へ送信されません：

  • 学習進捗（わかる／わからない の記録）、お気に入り ★ 単語
  • 間隔反復(SRS)スケジュール、1日の目標／連続学習日数(streak)／統計
  • カテゴリー選択、ダークモード／文字サイズ／通知設定、オンボーディング表示フラグ等

アプリを削除すると消去されます。[設定 → アプリ → リンク韓国語 → ストレージ → データを消去] でも削除できます。

4. 広告（Google AdMob）

運営費のため Google AdMob のバナー広告を表示します。AdMob は以下を収集する場合があります：

  • 広告 ID（Advertising ID — Android が提供する匿名識別子）
  • 端末情報（モデル、OS バージョン、言語、国）
  • 広告の表示／クリック統計

詳細は Google のプライバシーポリシーをご覧ください： https://policies.google.com/privacy / 広告 ID の管理。 利用者は [設定 → Google → 広告] で広告 ID をリセットできます。

5. 権限

  • INTERNET：広告 SDK の通信（学習コンテンツ自体はオフライン動作）
  • ACCESS_NETWORK_STATE：広告読み込み前のネットワーク状態確認
  • POST_NOTIFICATIONS：学習リマインダー（明示的にオンにした場合のみ）
  • RECEIVE_BOOT_COMPLETED：再起動後のリマインダー復元
  • AD_ID：AdMob 広告 ID（Android 13+ ポリシーに基づく明示宣言）

位置・カメラ・連絡先・マイク・ストレージ等の機微な権限は一切要求しません。

6. 児童のプライバシー（COPPA）

全年齢を対象とし、13歳未満の利用者の個人情報を意図的に収集しません。識別情報を収集しないため COPPA の規制対象には該当しません。

7. データセキュリティ

アプリ内の学習データ（単語・例文等）は AES-256-GCM で暗号化され APK にバンドルされます。

8. ポリシーの変更・お問い合わせ

変更がある場合はアプリの更新時にお知らせします。お問い合わせ： seguneman@gmail.com

English

1. Overview

This is an offline Korean vocabulary app for Japanese learners. We do not collect any personal information and do not transmit data to external servers. We use Google AdMob for ads, which may itself collect limited information.

2. Information We Do NOT Collect

Name, email, phone, address; location; contacts, photos, files, SMS; microphone, camera; login credentials (no login feature).

3. Information Stored Locally

Learning progress, favorites, SRS schedule, daily goal/streak, settings, onboarding flags — all in device localStorage, never sent externally. Removed on app deletion or via [Settings → Apps → リンク韓国語 → Storage → Clear Data].

4. Advertising (Google AdMob)

We display AdMob banner ads. AdMob may collect: Advertising ID, device info, ad impression/click stats. See Google's privacy policy and Ad ID management. Reset your Advertising ID via [Settings → Google → Ads].

5. Permissions

INTERNET, ACCESS_NETWORK_STATE, POST_NOTIFICATIONS (opt-in), RECEIVE_BOOT_COMPLETED, AD_ID (Android 13+ AdMob policy). We do not request sensitive permissions (location/camera/contacts/microphone/storage).

6. Children's Privacy (COPPA)

Suitable for all ages; does not knowingly collect data from users under 13. Not subject to COPPA.

7. Data Security

In-app learning data is AES-256-GCM encrypted and bundled inside the APK.

8. Changes & Contact

Policy changes announced via app updates. Contact: seguneman@gmail.com

한국어 (참고)

일본인 한국어 학습자를 위한 오프라인 단어장 앱입니다. 개인정보를 수집하지 않고 외부 서버 전송이 없습니다. 학습 진도는 기기 localStorage에만 저장됩니다. 무료 운영을 위해 Google AdMob 배너 광고를 사용하며, AdMob은 광고 ID 등을 수집할 수 있습니다(Google 정책 적용).
